## Limits and retained evidence

This release supervises single-node training on already allocated resources;
standalone offline eval uses one device. SSH profiles do not provision GPU jobs.
See [the capability table](../nsp.md) for supported algorithms and objectives.

The GPU image has no SGLang installation. Actual serving AL has HTTP protocol
coverage but has not been validated against a live SGLang engine. Dynamic serving
context bins require explicit per-cycle telemetry; request counters alone cannot
supply them. Offline prefix AL is not a claim about actual serving acceptance.
